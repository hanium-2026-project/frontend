# Hanium Smart Parking Frontend

React + TypeScript dashboard for the intelligent parking scheduling and control MVP.

## Setup

```bash
npm install
npm run dev
```

The local app runs at `http://127.0.0.1:5173/` by default.

## Build

```bash
npm run build
```

## Screens

- Dashboard
- Parking map
- Vehicle management
- Entry/exit simulation
- Route recommendation
